# Randolph Lemon Jr. | Project demos

Live demos of Tally (encrypted budgeting app) and Winter Block (training and nutrition tracker).
Both demos run on sample data and save only to the visitor's browser.

## Publish with GitHub Pages
1. Create a repository named `<your-username>.github.io` (or any name).
2. Upload everything in this folder to the repository root: `index.html`, `Randolph_Lemon_Resume.pdf`, `README.md`, and the `demos` folder.
3. Go to Settings > Pages, set Source to "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. The site goes live at `https://<your-username>.github.io/` within a minute or two.
