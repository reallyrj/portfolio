Tally

A private budgeting app that tells you where each paycheck should go.

Open the demo

Goal

I wanted a budget that works from real paychecks instead of a monthly guess, without handing my bank login to a third-party app. Everything stays on the device, and an optional passcode encrypts it.

How I built it

  1. Designed the budget model: fixed bills come out first, then percentage categories split what's left. Variable categories default to the last three months' average.
  2. Built six views (Month, Money, Plan, 90 Day, Goals, Worth) as a single-file web app with no framework.
  3. Added local-first storage, then optional encryption using the browser's Web Crypto API.
  4. Wrote a CSV parser so bank exports import directly, handling different date formats and negative amounts in parentheses.
  5. Added encrypted backups and auto-lock, then tested the restore paths.

Implementation

Encryption
PBKDF2-SHA256 with 310,000 iterations and a random 16-byte salt derives an AES-256-GCM key. Every save uses a fresh 12-byte IV.
Access control
Locks after 5 minutes in the background. A wrong passcode simply fails decryption, so no password hash is stored.
Input safety
All user text is escaped before rendering to block injected HTML.
Planning
Savings goals with contributions, a 90-day savings run with custom rules, and net-worth history.

JavaScript, HTML, CSS, Web Crypto API, localStorage

Winter Block

A training and nutrition tracker built to take me from 150 to 157 lb by the first day of winter.

Open the demo

Goal

Daily weight swings 2–3 lb on water alone, so I wanted a tracker that reacts only to real trends, adjusts calories by rule instead of mood, and shows whether strength is moving with the scale.

How I built it

  1. Set up the pace math: three paces (0.4, 0.5 and 0.75 lb a week), each with its own calorie target, counting down to December 21.
  2. Built the daily log and a 7-day moving average so the trend, not the daily number, drives decisions.
  3. Wrote the adjustment rules: a flat 4-week average adds 200 calories, gaining too fast removes 200, on pace holds.
  4. Added a training log with a 40-exercise library by muscle group, per-lift history, and detection of lifts that beat last session.
  5. Added meal planning, a budgeted grocery list and AI recipe ideas, then offline storage with account sync and JSON backups.

Implementation

Charts
Drawn in SVG: daily weigh-ins, the 7-day average, and the target pace line.
Nutrition
Protein and fat stay fixed; carbohydrates absorb every calorie change.
Storage
Saves to the device instantly and syncs to account storage after a short debounce, so it works offline.
AI recipes
Requests recipes from Claude as structured JSON, with cancel support for slow requests.

JavaScript, HTML, CSS, SVG
